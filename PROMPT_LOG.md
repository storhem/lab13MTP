## Code Review — финальная проверка перед сдачей

### Промпт 1 — Поиск критических дефектов

**Инструмент:** Claude Code

"Проведи полный code review проекта: все Python-модули оркестратора, llm-analyst агент, README. Ищи блокировки event loop, deprecated API, несоответствия конфигурации."

Результат:  
Найдено три дефекта. Первый — `gemini_client.py`: метод `analyze` объявлен как `async def`, но внутри вызывает синхронный `self.model.generate_content()`. Это блокирует event loop на всё время HTTP-запроса к Gemini API, что в нагруженной системе приводит к зависанию всего оркестратора. Исправление: заменил на `await self.model.generate_content_async()`. Второй — `orchestrator.py` line 62: `asyncio.get_event_loop()` deprecated с Python 3.10 и в определённых контекстах выбрасывает `DeprecationWarning` или создаёт новый loop вместо текущего; заменил на `asyncio.get_running_loop()`. Третий — README.md: порт оркестратора указан как 8000, хотя в docker-compose маппинг `8001:8000` — внешний порт 8001. Исправлены все три.
